# PingMe

An inquiry platform for beginners in tech. A high-end, editorial-style landing page built with React, Vite, Framer Motion, and Web3Forms.

## Features
- **Modern Design**: Minimalist, high-end monochrome aesthetic.
- **Inquiry Form**: Securely powered by Web3Forms (no email exposure).
- **Interactive Timeline**: A look into the journey of the maker.
- **Fully Responsive**: Optimized for all devices.

## Tech Stack
- React 19
- Vite
- Framer Motion (Animations)
- Lucide React (Icons)
- Web3Forms (Form handling)

## Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Create a `.env` file and add your `VITE_WEB3_FORMS_KEY`.
4. Run locally: `npm run dev`
